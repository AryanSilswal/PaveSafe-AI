**PaveSafe AI** | *Next.js, Node.js, FastAPI, PostgreSQL (PostGIS), YOLOv8, JWT* \hfill 2026
- Developed a full-stack, AI-powered infrastructure maintenance platform enabling citizens to seamlessly report road hazards and municipal authorities to manage repair dispatch workflows.
- Engineered a decoupled microservice architecture, integrating a Node.js API Gateway with a Dockerized Python FastAPI service utilizing YOLOv8 for automated, real-time hazard severity classification.
- Architected a spatial database utilizing PostgreSQL and PostGIS, implementing efficient geospatial queries for mapping coordinates and securing administrative operations via JWT role-based access control (RBAC).
- Implemented memory-efficient multipart/form-data streaming across cloud environments (Vercel and Render), reducing image processing bottleneck and ensuring rapid client-side feedback.
